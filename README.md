# YOLO26N-CLS-GAB
Multi-classification Model for Atopic Skin Disease Detection

## 📌 Project Overview
This project focuses on atopic skin disease detection. A multi-class classification model is developed to enable automatic recognition of skin lesion images, offering algorithmic support for computer-aided skin disease diagnosis.

## 📊 DHIS Dataset
We constructed the DHIS dataset covering six skin disease categories.
Dataset access: [ScienceDB Download Link](https://www.scidb.cn/s/BFNN7f)

## 🧠 Trained Model Weights
Trained model files (`.pt`, `.onnx`, `fp32.engine`, `fp16.engine`) trained on the DHIS dataset are provided for the following model variants:
- YOLO26n-cls
- YOLO26n-cls-A
- YOLO26n-cls-A+B
- YOLO26n-cls-GAB

Model download:[Google Drive Download Link](https://drive.google.com/drive/folders/1rD7F847oeSdlmwNRTdeCBtSvrOGN1HP5?usp=drive_link)
